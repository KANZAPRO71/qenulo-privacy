Bahasa IndonesiaEnglishKebijakan Privasi / Privacy Policy

1. Di mana data Anda disimpan

Qenulo AI tidak memiliki akun pengguna dan tidak memiliki server sendiri. Semua data aplikasi disimpan hanya di perangkat Anda:

  • riwayat soal dan hasil penyelesaian;
  • kemajuan belajar, kartu belajar (flashcard), dan lencana;
  • pengaturan (bahasa, jenjang, mode belajar, tema, pengingat);
  • kunci API Gemini Anda, di penyimpanan aman sistem (Android Keystore).

Karena itu, Anda dapat menghapus semua data sendiri langsung di perangkat, tanpa perlu mengirim permintaan kepada kami.

2. Langkah menghapus data

  1. Hapus kunci API Gemini di aplikasi: buka tab Profil → Buka pengaturan → bagian Kunci Gemini → ketuk Hapus kunci API → konfirmasi Hapus. Kunci langsung dihapus dari penyimpanan aman perangkat.
  2. (Opsional) Hapus riwayat soal di aplikasi: buka layar Riwayat soal → ketuk Hapus riwayat.
  3. Hapus semua data aplikasi: buka Pengaturan Android → Aplikasi → Qenulo AI → Penyimpanan → Hapus data (nama menu bisa sedikit berbeda tergantung merek ponsel). Ini menghapus riwayat, kemajuan, pengaturan, dan kunci API.
  4. Copot pemasangan Qenulo AI. Mencopot aplikasi juga menghapus semua data aplikasi di perangkat.

Jika Anda pernah membuat file cadangan (ekspor backup) atau membagikan teks dari aplikasi, file/teks tersebut berada di lokasi yang Anda pilih sendiri dan perlu Anda hapus di sana.

4. Data yang diproses oleh Google Gemini

Saat Anda memakai fitur AI, foto, PDF, teks soal, dan audio suara dikirim langsung dari perangkat ke Google Gemini API dengan kunci API Anda sendiri. Qenulo / Devi Core tidak menyimpan data ini dan tidak dapat menghapusnya atas nama Anda. Penyimpanan dan penghapusannya diatur oleh Google:

  • Ketentuan Layanan Gemini API
  • Kebijakan Privasi Google

Anda dapat mengelola atau mencabut kunci API di Google AI Studio (menghapus kunci membuatnya tidak dapat dipakai lagi), dan mengelola data akun Google Anda di Akun Google.

5. Masa retensi

Devi Core tidak menyimpan data pengguna Qenulo AI di server mana pun, sehingga tidak ada masa retensi tambahan di sisi Qenulo. Data di perangkat hilang segera setelah Anda menghapus data aplikasi atau mencopotnya.

Data Deletion - Qenulo AI

App: Qenulo AI (Android, package ai.qenulo.study)
Developer: Devi Core
Last updated: 10 October 2026

1. Where your data is stored

Qenulo AI has no user accounts and no servers of its own. All app data is stored only on your device: solve history and results; learning progress, flashcards and badges; settings (language, grade, study mode, theme, reminders); and your Gemini API key in the system's secure storage (Android Keystore). You can delete everything yourself on the device; no request to us is needed.

2. How to delete your data

  1. Remove your Gemini API key in the app: Profile tab → Open settings → Gemini key section → tap Remove API key → confirm Remove. The key is deleted from the device's secure storage immediately.
  2. (Optional) Clear solve history in the app: open Solve history → tap Clear history.
  3. Clear all app data: Android Settings → Apps → Qenulo AI → Storage → Clear data (menu names vary slightly by phone brand). This removes history, progress, settings and the API key.
  4. Uninstall Qenulo AI. Uninstalling also removes all app data on the device.

Backup files you exported or text you shared from the app are wherever you chose to save or send them; delete them there.

4. Data processed by Google Gemini

When you use AI features, photos, PDFs, typed questions and voice audio are sent directly from your device to the Google Gemini API using your own API key. Qenulo / Devi Core does not store this data and cannot delete it on your behalf. Its retention and deletion are governed by Google's Gemini API Terms of Service and Privacy Policy. You can manage or delete your API key in Google AI Studio and manage your Google account data in Google Account.

5. Retention period

Devi Core keeps no Qenulo AI user data on any server, so there is no additional retention period on the Qenulo side. On-device data is gone as soon as you clear the app data or uninstall the app.
