Kebijakan Privasi Qenulo AI

Aplikasi: Qenulo AI (Android, ID paket ai.qenulo.study)
Pengembang: Devi Core
Tanggal berlaku: 10 Oktober 2026

Bahasa IndonesiaEnglish

1. Ringkasan

Qenulo AI adalah aplikasi belajar yang membantu siswa memahami soal (foto, PDF, ketik, atau suara) dengan bantuan model AI Google Gemini. Qenulo tidak memiliki akun pengguna dan tidak memiliki server sendiri yang menyimpan data Anda. Data belajar Anda disimpan di perangkat Anda sendiri.

2. Kunci API Gemini milik Anda (BYOK)

Qenulo memakai model "bawa kunci sendiri" (Bring Your Own Key): Anda memasukkan kunci API Google Gemini milik Anda sendiri di Pengaturan. Kunci tersebut disimpan hanya di perangkat, di penyimpanan aman sistem (Android Keystore melalui expo-secure-store), dan hanya dikirim ke Google sebagai bagian dari permintaan ke Gemini API. Kunci tidak pernah dikirim ke pengembang.

Build uji (misalnya untuk pengujian internal/tertutup) dapat berisi kunci uji milik pengembang agar penguji bisa langsung mencoba aplikasi. Dalam hal itu, permintaan Anda diproses oleh Gemini API dengan kunci pengembang, tetapi isi permintaan tetap tidak dikirim ke server pengembang.

3. Data yang dikirim ke Google Gemini API

Agar fitur AI berfungsi, konten berikut dikirim langsung dari perangkat Anda ke Google Gemini API (generativelanguage.googleapis.com) saat Anda memakai fitur terkait:

  • Foto soal yang Anda ambil dengan kamera atau pilih dari galeri;
  • File PDF / dokumen yang Anda unggah;
  • Teks soal yang Anda ketik dan pertanyaan di chat tutor;
  • Audio suara dari mikrofon selama sesi Tutor Suara (dialirkan langsung ke Gemini Live), beserta transkripnya.

Pemrosesan oleh Google tunduk pada Ketentuan Layanan Gemini API dan Kebijakan Privasi Google. Jika Anda memakai kunci API pada tingkat gratis, Google dapat menggunakan konten untuk meningkatkan produknya sesuai ketentuan tersebut. Mohon jangan mengirim informasi pribadi yang sensitif dalam foto, dokumen, atau suara.

4. Data yang disimpan di perangkat

Riwayat soal, hasil penyelesaian, kemajuan belajar, kartu belajar (flashcard), lencana, dan pengaturan (bahasa, jenjang, mode belajar, tema) disimpan secara lokal di perangkat Anda. Pengingat belajar memakai notifikasi lokal yang dijadwalkan di perangkat; tidak ada notifikasi push dari server.

Fitur cadangan (backup) hanya membuat file ekspor ketika Anda memintanya, dan file itu dikirim ke tujuan yang Anda pilih sendiri (misalnya aplikasi berbagi). Fitur "Bagikan" hanya membagikan teks yang Anda pilih untuk dibagikan.

5. Yang tidak kami lakukan

  • Tidak ada akun Qenulo, login, atau server Qenulo yang menyimpan data Anda.
  • Tidak ada SDK analitik, pelacakan, atau pelaporan crash pihak ketiga (misalnya Firebase, Sentry) di aplikasi.
  • Tidak ada iklan.
  • Kami tidak menjual atau menyewakan data Anda kepada siapa pun.

6. Izin aplikasi

  • Kamera: hanya untuk memotret soal ketika Anda membuka fitur Foto Soal.
  • Mikrofon (dan pengaturan audio): hanya selama Anda memakai Tutor Suara.
  • Notifikasi: untuk pengingat belajar lokal, jika Anda mengizinkannya.

Izin dapat dicabut kapan saja melalui Pengaturan Android; fitur terkait lalu tidak dapat digunakan.

7. Anak-anak dan pelajar

Qenulo adalah aplikasi pendidikan untuk pelajar. Pengguna di bawah 13 tahun sebaiknya memakai aplikasi dengan bimbingan dan izin orang tua/wali, termasuk dalam pembuatan dan penggunaan kunci API Google. Qenulo tidak meminta nama, email, atau data identitas lain, dan tidak secara sengaja mengumpulkan data pribadi anak.

8. Menghapus data

  • Hapus kunci API: buka Pengaturan → bagian kunci API Gemini → hapus/kosongkan kunci. Anda juga dapat mencabut kunci di Google AI Studio.
  • Hapus riwayat: gunakan tombol hapus riwayat di aplikasi.
  • Hapus semua data: Pengaturan Android → Aplikasi → Qenulo AI → Penyimpanan → Hapus data, atau copot pemasangan aplikasi.

Karena pengembang tidak menyimpan data Anda di server, tidak ada data di sisi pengembang yang perlu dihapus. Data yang telah diproses Google tunduk pada kebijakan Google.

Qenulo AI Privacy Policy

App: Qenulo AI (Android, package ai.qenulo.study)
Developer: Devi Core
Effective date: 10 October 2026

1. Summary

Qenulo AI is a study app that helps students understand problems (photo, PDF, typed or voice) using Google's Gemini AI models. Qenulo has no user accounts and no servers of its own that store your data. Your learning data stays on your device.

2. Your own Gemini API key (BYOK)

You enter your own Google Gemini API key in Settings. It is stored only on your device in the system's secure storage (Android Keystore via expo-secure-store) and is only sent to Google as part of Gemini API requests. It is never sent to the developer. Test builds (e.g. internal/closed testing) may include a developer test key so testers can use the app right away; requests are then made to the Gemini API with that key, and their content is still not sent to any developer server.

3. Data sent to the Google Gemini API

When you use the related features, the following is sent directly from your device to the Google Gemini API (generativelanguage.googleapis.com): photos of problems you take or pick; PDF/documents you upload; typed questions and tutor chat messages; and microphone audio during Voice Tutor sessions (streamed to Gemini Live) together with its transcription. Google's processing is governed by the Gemini API Terms of Service and the Google Privacy Policy. On the free tier, Google may use content to improve its products under those terms. Please avoid sending sensitive personal information.

4. Data stored on your device

Solve history, results, learning progress, flashcards, badges and settings are stored locally on your device. Study reminders are local notifications scheduled on the device; there are no server push notifications. Backups are only created when you export them, and go to a destination you choose. "Share" only shares the text you choose to share.

5. What we do not do

  • No Qenulo accounts, logins or Qenulo servers storing your data.
  • No third-party analytics, tracking or crash-reporting SDKs (e.g. Firebase, Sentry).
  • No ads.
  • We do not sell or rent your data.

6. Permissions

Camera: only to photograph a problem when you use Photo Solve. Microphone (and audio settings): only while you use the Voice Tutor. Notifications: for local study reminders if you allow them. You can revoke permissions at any time in Android Settings.

7. Children and students

Qenulo is an educational app for students. Users under 13 should use it with the guidance and consent of a parent or guardian, including when creating and using a Google API key. Qenulo does not ask for names, emails or other identifying information and does not knowingly collect children's personal data.

8. Deleting your data

Remove the API key in Settings (Gemini API key section), and/or revoke it in Google AI Studio. Clear history with the in-app clear button. Remove everything via Android Settings → Apps → Qenulo AI → Storage → Clear data, or by uninstalling the app. The developer holds no copy of your data on any server. Data processed by Google is subject to Google's policies.
